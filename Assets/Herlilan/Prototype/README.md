# 石头状态转换原型

关联议题：[#3 石头状态与成绩怎样判定](https://github.com/JunduoLiu/RockBalancing/issues/3)。本目录保留早期讨论用原型，不作为当前首版实现或验收依据。

历史原型说明（2026-11-10）：下述稳定计分、本局最高纪录、平面物理和鼠标操作属于旧实验方案，已被 [规格 #9](https://github.com/JunduoLiu/RockBalancing/issues/9) 与 [最终规则 #10](https://github.com/JunduoLiu/RockBalancing/issues/10) 取代。当前手机玩法位于 `Assets/RockBalancing`，入口为 `Assets/RockBalancing/Scenes/Balance.unity`；保留本目录不会将其加入该场景。

## 运行

1. 用 Unity 6000.3.20f1 打开项目，等待编译。
2. 选择菜单 `Herlilan > Prototype > Open Stone State Prototype`。当前场景有修改时会先提示保存。
3. 点击 Play，在 Game 视图使用鼠标和按钮。原型场景是临时场景，可以自行另存到本目录。

## 观察

- 横向正交侧视镜头；蓝色待摆石头直接跟随鼠标左右、上下移动，高度范围 0.3–9，深度固定在场地中线。鼠标移入操作面板或移出 Game 视图时暂停跟随。
- 右键拖动时暂停移动并旋转石头；松开右键后鼠标回到石头中心的屏幕位置，再恢复跟随，避免石头跳动。左键直接释放，也可使用 Release 按钮；高度由鼠标位置控制，不再使用滚轮。
- 每颗石头采用随机扰动顶点与比例的多面体，使用对应的凸网格碰撞体。
- 释放：无重叠则转为灰色已释放石头，交给物理；重叠则拒绝并保留待摆状态。
- 丢弃：暂时采用按钮，将石头放到场地右侧后转为橙色弃石，保留物理碰撞。
- 释放或丢弃后 0.6 秒生成下一颗；可在上一颗仍运动时继续操作。
- 已释放石头和弃石不可重新拿取，倒塌不清场。
- 重开清除全部石头并生成新的待摆石头。
- 面板显示最近六条转换记录。
- 计分面板显示当前稳定高度、当前分数与本局最高纪录。原型按高度乘以 100 向下取整；石头连续 0.75 秒低于线速度 0.05、角速度 0.1 的阈值（或休眠），且通过同样稳定的已释放石头连接地面才计高。弃石与仅由弃石连接地面的石头不计高。这是接触连通近似，尚不等于正式承重判定。
- 倒塌后当前分数随稳定高度变化，本局最高纪录保留；重开同时清零。
- 在上述单颗稳定检查之后，候选塔高还须在 0.02 单位容差内保持 1 秒才更新分数和最高纪录，面板显示确认进度。高度下降立即撤去失效高度对应的当前分数；最高纪录保留。
- 暂时采用横向平面物理：锁定 Z 位置和 X/Y 轴旋转，仅允许 X/Y 平移及绕 Z 轴翻倒。右键水平拖动只在画面平面内旋转；弃石也保持在该平面内。

## 试玩边界

生成中的状态同步完成，不专门停留显示。稳定和倒塌不作为生命周期状态。生成形状为试验用低面数不规则石头，计高与分数也是试验规则，未实现正式生成方案或纪录分享。丢弃方式、供给延时、移动范围、稳定阈值与重叠容差均为实验设置，尚待讨论。移动端触控与布局尚未验证；请先在桌面 Game 视图试玩。
