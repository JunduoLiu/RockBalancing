# Domain Docs

布局：single-context。

探索项目之前，读取根目录 CONTEXT.md 和与当前工作相关的 docs/adr/。
缺少文件时继续；术语或决策真正形成后，由 domain-modeling 按需创建。
领域文档使用 CONTEXT.md 定义的词汇及其 Avoid 约束。
方案与现有 ADR 冲突时，明确指出冲突及重新讨论的理由。

CONTEXT.md 是领域术语来源。
docs/adr/ 保存已确认的架构决策。
未决问题、决策讨论与历史结论在 GitHub Issues 中读取，入口见[决策地图](https://github.com/JunduoLiu/RockBalancing/issues/1)。
PROPOSAL.md 仍为待团队评审的分工建议。
