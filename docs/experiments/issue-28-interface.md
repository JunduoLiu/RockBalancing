# #28 精简游戏界面

基线：`ed057ec`，需求：[Issue #28](https://github.com/JunduoLiu/RockBalancing/issues/28)。本票只做界面精简，不包含后续相机、图标和键盘票。

## 实现

- 删除“查看全景”按钮、全景模式状态和专用取景/切换分支。普通环绕、缩放、调整时锁定、松手跟随、换石衔接和重开视角保持原契约。
- 删除标题、副标题、常驻说明栏。高度 / `stablizing` 位于左上，重开和分享位于右上；释放/弃置紧贴底部调整区上方，释放出的中部空间供观察。
- 删除所有“落点”屏幕边缘方向标签及重叠错位逻辑。待摆石头边缘提示仍可用，不拦截触控；场景中的落点圆环、竖线和石头描边保留。
- 碰撞拒绝使用现有两秒反馈寿命，只在有消息且没有弹窗时显示非交互提示。等待供石时只保留重试入口，不重复显示说明栏。
- 文本在短横屏窗口中按可用空间缩小，避免 Unity Text 因高度不足而整段消失。高度和 stablizing 分别以 44 / 28 为字号上限。
- 分享仍由独立的完整现场相机取景，与已删除的游玩全景无关。
